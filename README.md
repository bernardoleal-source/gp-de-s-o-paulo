📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática para colocar em prática os conhecimentos adquiridos nas aulas de HTML e CSS.

O objetivo foi recriar uma página inspirada no Grande Prêmio de São Paulo de Fórmula 1, realizado no Autódromo de Interlagos, buscando deixar o visual o mais parecido possível com a referência, tanto no computador quanto no celular.

🎯 Objetivo

Desenvolver uma página organizada, bonita e responsiva, utilizando apenas HTML e CSS, trabalhando diferentes recursos de estilização e estruturação.

🧰 Tecnologias utilizadas

HTML5: estruturação da página.

CSS3: estilização e organização dos elementos.

Google Fonts: utilização de fontes personalizadas.

Flexbox: organização do topo, banner principal e filtros.

CSS Grid: disposição dos cards dos pilotos.

Media Queries: adaptação da página para celulares.

:root: criação de variáveis com as cores das equipes.

🏁 O que a página apresenta?

Banner principal inspirado no GP de São Paulo.

Cards com informações dos pilotos e suas equipes.

Filtros para organização dos pilotos.

Formulário para compra de ingressos.

Tabela de classificação.

Layout adaptado para computadores e celulares.

Imagem de fundo e detalhes inspirados na pista de Interlagos.

📱 Responsividade

O projeto utiliza Media Queries para adaptar os elementos da página a diferentes tamanhos de tela, proporcionando uma melhor experiência tanto em computadores quanto em dispositivos móveis.

📚 Aprendizados

Durante o desenvolvimento, foi possível praticar a criação de páginas com HTML e CSS, entender melhor o funcionamento de Flexbox e Grid, trabalhar com cores personalizadas e aprender a deixar um site responsivo.
